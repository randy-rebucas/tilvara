# Tilvara — Full audit (2026-10-31, session 47)

The fourth full audit of the code. It follows [the session 45 audit](AUDIT-2026-10-27.md), whose fixes are in commit `f8c08c1` with migrations 0134–0135. Nothing new was built since; this audit checks those fixes and looks again at every area.

This was the report. The user asked to fix every finding ("fix all finding"), and every one was fixed in the same session with the recommendations of §4: see §5.

### Info (no action proposed unless wanted)
- API-key reads have no rate limit at all, while ADR-0019 assumes "the existing per-IP limits", which no GET route has. A per-key bucket, or a corrected ADR.
- `GET /api/session-ended` can be reached by a cross-site link and clears the cookies, but the session stays valid. It only signs the browser out.
- `billing_dev_checkout_open(text)` is executable by `onepos_app` in every environment. It returns a boolean, for DEV checkouts only.
- On dev, every stock movement from before 0134 has `balance_seq` NULL, and 66 balances have `movement_seq = 0`. This is harmless (NULLs drop out of `movedSinceFreeze`), but worth a line in ADR-0012 amendment 3.
- The batch trace keeps the oldest 5,000 lot movements and does not say it cut the list, so a long recall loses its newest sales. Add `truncated`, or order newest first.
